## Шаблоны переменных (голубой океан — конкурентов нет)

### Tier 1 — высокий спрос, нужны всем

| Шаблон | Что делает | Почему нужен |
|--------|-----------|--------------|
| **UTM-параметр** | Извлекает конкретный UTM из URL (utm_source, utm_medium и т.д.) | Встроенного нет, все делают руками через JS |
| **Cookie Value** | Читает значение конкретной cookie по имени | Базовая потребность, нет в галерее |
| **URL Query Parameter** | Извлекает один GET-параметр по имени | Удивительно, но отсутствует |
| **localStorage / sessionStorage** | Читает значение из хранилища по ключу | Нужно для SPA, quiz-платформ, корзин |

### Tier 2 — продвинутые, показывают экспертизу

| Шаблон | Что делает | Почему нужен |
|--------|-----------|--------------|
| **Яндекс Метрика Client ID** | Достаёт `_ym_uid` из cookie | Нужен для сквозной аналитики, связки с CRM |
| **Тип устройства** | Возвращает mobile / tablet / desktop | Для условных тегов по типу устройства |
| **Источник трафика** | Парсит referrer → organic / social / direct / referral / paid | Для триггеров по типу источника |
| **Домен реферера** | Извлекает чистый домен из `document.referrer` | Для фильтрации по конкретным площадкам |
| **Первый / текущий UTM** | Сохраняет UTM первого визита в cookie, отдаёт first-touch или last-touch | Атрибуция без внешних сервисов |

## Шаблоны тегов

### Tier 1 — очевидные пробелы, массовый спрос

| Шаблон | Почему это дыра |
|--------|----------------|
| **VK Реклама (пиксель)** | Крупнейшая рекламная платформа РФ — и нет шаблона |
| **Top.Mail.ru** | Рейтинг Mail.ru стоит на миллионах сайтов |
| **Mindbox** | Один из главных CDP в России, нет шаблона |
| **Roistat** | Популярная аналитика, нет шаблона |
| **UIS / CoMagic** | Коллтрекинг — конкурент Calltouch, которого нет |

### Tier 2 — утилитарные (не привязаны к конкретному сервису)

| Шаблон | Что делает |
|--------|-----------|
| **Cookie-баннер 152-ФЗ** | Показывает баннер согласия, пишет cookie, блокирует теги до согласия. Актуальная тема compliance |
| **Core Web Vitals → Метрика** | Замеряет LCP/FID/CLS, отправляет как цели в Яндекс Метрику |
| **Универсальный Webhook** | Отправляет POST-запрос с данными на любой URL. Покрывает интеграции с CRM, BI, ботами |
| **JS Error Tracker** | Ловит `window.onerror` / `unhandledrejection`, отправляет в dataLayer или внешний сервис |
| **Scroll Depth → Метрика** | Отправляет цели при 25% / 50% / 75% / 100% прокрутки (есть встроенный триггер, но нет готового тега-отправщика) |

## Приоритет реализации

Если цель — максимум установок и узнаваемость агентства:

1. **UTM-параметр** (переменная) — проще всего сделать, нужен абсолютно всем, конкурентов ноль
2. **Cookie Value** (переменная) — то же самое, базовая потребность
3. **VK Реклама** (тег) — огромный спрос, удивительно что этого нет
4. **Cookie-баннер 152-ФЗ** (тег) — актуальная тема, показывает экспертизу в compliance

Переменные быстрее в разработке и ревью, а спрос на них будет стабильный, потому что это утилиты. Теги привлекают больше внимания, но и конкуренция за аудиторию выше.
